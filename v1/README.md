# v1｜第一個完整可展示版本（SafeRoad Studio v3）

> 這是本組保留的第一個展示版本。前期程式從單一資料與基本地圖起步，後續完成 2024–2026 多來源匯入、三角色驗證，以及 `app_v3.py` 六個分析空間。為保存版本脈絡，本資料夾命名為 **v1**；Dashboard 入口的檔名仍為 `app_v3.py`。

## 1. 研究目的與範圍

以臺灣警政署公開的 A1／A2 交通事故紀錄，探索歷史資料在地點、時間、天候、事故類別與主要肇因上的分布。重點是**可重現的資料檢查 → 分析 → 獨立審查**，而不是以歷史事故件數預測某個人在路上發生事故的機率。

本版只使用真實官方事故來源作為正式分析輸入。程式單元測試可能採用隔離的測試 fixture，但不把那些資料當成真實事故展示。

## 2. 目前已實作功能

| 模組 | 功能 | 產物／說明 |
|---|---|---|
| 原始資料與品質管理 | 多份 CSV／JSON／ZIP 合併、欄位正規化、缺值與座標檢查、SHA-256 來源記錄 | `outputs/01_normalized.csv`、`01_quality.json` |
| 事故分布分析 | 來源紀錄的年度、24 小時、天候、事故類別、縣市、主要肇因統計 | `02_summary.json` |
| 空間分布 | 有效座標事故點、群聚檢視、統計格網，OpenStreetMap 底圖 | `02_hotspots.csv`、`dashboard.html`、v3 地圖 |
| 道路探索 | 道路／地點文字查詢、常見位置與原因排行 | v3「道路探索」 |
| 地區比較 | 縣市與年度資料列比較 | v3「地區比較」 |
| 可追溯性 | 資料來源、品質摘要、第三角色獨立核對、篩選後 CSV 匯出 | `03_audit.json`、`03_report.md` |
| Skill 架構 | YAML metadata、三角色任務規範、可執行 Python 流程與測試 | `SKILL.md`、`agents/`、`scripts/`、`tests/` |

### Dashboard v3 六個分頁

1. **全局總覽**：資料摘要、年份趨勢、類別分布。
2. **事故地圖**：群聚、密度格網、歷史點位探索。
3. **時間解碼**：24 小時分布、年×月熱力圖、天候比較。
4. **道路探索**：輸入地點／路名文字查詢歷史資料列。
5. **地區比較**：縣市、年份比較（需注意各年度涵蓋期間）。
6. **方法與驗證**：來源、稽核、檔案匯出。

## 3. 這一版已產生的真實分析結果

以下為此版 `outputs/` 中保留的處理結果，**不是目前 Dashboard 畫面任何篩選條件下的筆數**，更新來源資料後會改變。

| 指標 | 執行紀錄 |
|---|---:|
| 合併原始來源資料列 | 2,254,292 |
| 有效地圖座標資料列 | 2,246,830 |
| 無效座標排除資料列 | 7,462 |
| 標記完全重複來源資料列 | 92（僅標記，未直接刪除） |
| 資料涵蓋年份 | 2024、2025、2026（2026 年為部分期間） |
| Agent 3 檢查結果 | `PASS` |

`PASS` 代表既定的計數、座標範圍與格網勾稽檢查通過，**不是保證每一筆政府資料都絕對正確，也不是 Skill 自動觸發測試通過**。

**重要的統計口徑：** 官方資料可按當事者建立多列紀錄，這個版本未驗證每筆資料都有唯一事故 ID，因此顯示的是**來源資料列數**，不能寫成「發生 2,254,292 件交通事故」。也不能把沒有交通流量分母的熱點數量視為道路事故風險率。

## 4. 三位角色與交接

| 角色 | 職責 | 輸入 | 輸出 |
|---|---|---|---|
| Agent 1 — Inspector | 取得與檢查真實原始檔、欄位映射、GPS 驗證 | 官方 JSON／CSV／ZIP | `01_normalized.csv`、`01_quality.json` |
| Agent 2 — Analyst | 計算資料列統計、時間分布及地理格網 | Agent 1 輸出 | `02_summary.json`、`02_hotspots.csv`、`dashboard.html` |
| Agent 3 — Auditor | 重新勾稽數量與座標結果、提出限制 | 前兩者輸出 | `03_audit.json`、`03_report.md` |

這三份 `.md` 是三個角色的工作指令；本地 Python 管線是**依序執行的確定性分析**，不能直接說成三個獨立 AI 同時運作。

## 5. 完整執行方式（Windows CMD / VS Code）

在 GitHub 根目錄雙擊 `SafeRoad_操作選單.cmd`，或先進入本資料夾：

```cmd
cd v1
python -m pip install -r requirements.txt
```

### A. 準備真實官方資料

將下載的檔案放在 `v1/data/raw/`，例如：

```text
v1/data/raw/
  2024_A1_A2_official.zip
  2025_A1_A2_official.zip
  2026_A1.json
  2026_A2_01.zip ... 2026_A2_07.zip
```

可以使用內附 `下載2024_2025官方事故資料.cmd` 和 `下載2026年官方事故資料.cmd`，或到官方網站自行下載。下載工具若失敗，改採手動下載；**請勿使用合成事故資料取代**。

- [2024 年度 A1／A2](https://data.gov.tw/dataset/172969)
- [2025 年度 A1／A2](https://data.gov.tw/dataset/177136)
- [A1 資料](https://data.gov.tw/dataset/57023)
- [A2 資料](https://data.gov.tw/dataset/57024)

2026 的 ZIP 分包與前兩年度資料可能有不同結構，需通過既有解析與品質檢查。避免同一期間同時放入「月檔」與「年度彙整檔」，以免重複計數。

### B. 執行全部三角色資料分析

```cmd
python scripts\run_all.py
```

這步會建立 `outputs/01_*`、`02_*`、`03_*`；先開 `outputs/03_audit.json`，確認 `status` 為 `PASS`。

### C. 開啟新版 Dashboard（一定是 app_v3）

```cmd
python -m streamlit run app_v3.py
```

開啟終端機顯示的 `http://localhost:8501`（如連接埠被占用，依實際顯示網址）。**不要改用舊版 `app.py`**。

### D. 執行程式測試

```cmd
python -m pytest -q
```

測試可檢查程式邏輯，不等於教授要求的 AI Skill A／B／C 自動觸發測試。

## 6. 如何在 Dashboard 看結果

1. **全局總覽**：確認目前篩選條件與資料筆數、涵蓋年度。
2. **事故地圖**：切換群聚／格網，縮放地圖並觀察點位；底圖需網路，但來源事故數據可離線重算。
3. **時間解碼**：比較月份、時段與天候；2026 為部分年份，勿直接與完整年度推算增減。
4. **道路探索**：輸入「中正路」等路名，觀察相符的**歷史地點紀錄**及肇因。
5. **地區比較**：勾選需要比較的縣市與年份，留意原始資料列數不等於交通風險率。
6. **方法與驗證**：查看來源紀錄、Agent 3 驗證狀態、下載篩選結果。

## 7. 已知限制與後續工作

**目前沒有**：即時事故警報、真實導航路線安全分數、個別傷者送醫或就醫資料、自動派遣救護車、經交通流量校正的事故率。路名查詢是文字比對，不等於已準確定位同名路段。

目前官方資料與產出檔案體積較大，`v1/.gitignore` 預設排除 `data/raw/` 和 `outputs/`。如果從 GitHub Clone，看不到網頁結果屬正常：先下載真實資料並重新執行分析。避免把含敏感資訊的原始資料及數百 MB 的正規化 CSV 直接 Commit。

完整授課成果尚需：Skill 自動觸發 A／B／C 真實紀錄、五分鐘操作影片與字幕、AI Tutor 問答與交件資料。這些與已完成的程式測試應分開記錄。

## 8. 專案結構與來源

```text
v1/
├── app_v3.py              # 目前展示介面
├── SKILL.md               # Skill 定義
├── agents/                # 三角色工作規範
├── scripts/               # 資料下載、清理、分析與審查
├── tests/                 # 單元測試與啟動測試案例模板
├── data/raw/              # 官方真實資料（可能不入庫）
├── outputs/               # 執行結果（可能不入庫）
└── requirements.txt
```

資料來源：內政部警政署相關交通事故開放資料，入口為[政府資料開放平臺](https://data.gov.tw/)。展示版本不以任何一份平台來源承諾即時事故更新。
