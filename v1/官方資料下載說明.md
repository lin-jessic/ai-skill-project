# SafeRoad 官方交通事故資料下載操作

> 這是**下載工具包**，不是已下載的政府原始事故資料。此環境無法連上政府下載主機，因此未附上冒充真實資料的 CSV/JSON。

## 你目前 VS Code 專案的正確路徑

`C:\Users\user\Desktop\1118_ch_Safe\1118_ch\data\raw\`

## 操作

1. 解壓此 ZIP。雙擊 `下載2026_A1_A2資料.cmd`。
2. 它會下載 1 個 A1 JSON 與 7 個 A2 ZIP 到**下載包自己的** `data/raw/`。
3. 複製這 8 個 JSON/ZIP 到你原本專案的 `data/raw/`；**不要複製 `*.source.json` 作為事故檔**（它只是下載來源紀錄，可保留）。
4. 在原專案根目錄執行 `python scripts\run_all.py`；成功後 `python -m streamlit run app.py`。
5. 一次只用 2026 這組：不要再放涵蓋相同月份與 A1/A2 的年度彙整 ZIP，避免重複統計。

## 程式限制

- A2 下載檔可能很大；網路不穩可以從官方網頁逐份下載。
- 若 ZIP 裡沒有 CSV/JSON，或政府修改 JSON schema，原專案仍可能要增修讀取器。
- A1/A2 官網的「即時」不代表現場即時交通事件。
- 本下載包沒有下載醫院個案、送醫個案資料，也沒有編造資料。
