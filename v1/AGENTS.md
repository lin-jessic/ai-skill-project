# Shared repository rules

This project uses one Skill with three sequential role guides: `agents/01_inspector.md`, `agents/02_analyst.md`, `agents/03_auditor.md`.
Read `SKILL.md` before traffic-accident analysis. Never silently create accident records. Distinguish source data, derived aggregates and test fixtures. Preserve raw data; execute auditor before publishing results. Do not claim automatic Skill activation from local Python execution.
