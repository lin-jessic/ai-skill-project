# v4 整合說明

## 從 v2 保留的優點

- 官方資料下載器會從 data.gov.tw 資源頁找實際下載連結，不使用假檔案。
- 下載有政府網域檢查、大小限制、暫存檔、SHA-256 與 `official_download_manifest.json`。
- `SKILL.md` 的觸發邊界、三角色交接與法律風險界線完整。
- 教授檔案流程會輸出市場、法規、程序和 `04_audit.json`。

## 從 v3 保留的優點

- FastAPI PWA 介面，支援桌面瀏覽器與 HTTPS 部署後的行動裝置安裝。
- 20 種店型、商圈排行、財務情境、逐日決策模擬與 REST API。
- 上傳檔案限制、CSV/JSON 欄位驗證、來源 SHA-256 與 pytest 測試。
- `verify_web.py`、PWA manifest、service worker 和一鍵啟動檔。

## v4 修正的問題

1. v3 的官方下載器對非稅籍資料只提示手動下載；v4 恢復 v2 的自動解析官方資源頁與年度／月份選擇。
2. v3 的啟動文件仍有部分「替換 v2」文字；v4 改成獨立資料夾、自洽的 `START_V4.cmd` 與 `CHECK_V4.cmd`。
3. v2/v3 的快速入口散落多個 CMD；v4 以 `README_FIRST.txt`、`START_V4.cmd`、`CHECK_V4.cmd` 為主入口，舊檔案仍保留供相容。
4. 新增 `preflight_v4.py`，在安裝依賴與啟動服務前先檢查三角色、PWA、下載器與範例資料是否存在。

## 尚未宣稱完成的事項

- 官方資料實際下載成功與否取決於來源網站當時可用性，須看 manifest。
- 官方原始資料仍需依欄位、期間與地理範圍做 ETL，不能直接混加。
- 網站上的「執行分析」不等於 AI 模型自動載入 Skill；A/B/C 觸發證據仍需在支援 Skill 的 AI 工具中留存。
