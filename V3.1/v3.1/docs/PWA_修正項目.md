# OpenShop LIFE — GitHub v2 改版與 Debug 紀錄

基準：`lin-jessic/ai-skill-project`，`main/v2`（2026-11-25）

| 原版問題／限制 | 新版處理 |
|---|---|
| 左側欄放所有控制，與各分頁重複 | PWA 移到專屬建立店鋪／財務／通路頁面，手機底部導覽 |
| 無原生 HTML head / Service Worker | 新增 FastAPI 提供獨立 `web/` HTML，含 manifest、圖示及 SW |
| CSV/JSON 上傳後三 Agent 與報告不易看清 | 上傳獨立頁面、明確流程、來源雜湊、五份成果匯出 |
| 商圈權重超過 100% 可能變負值 | 新版滑桿互相約束，剩餘權重 >= 0 |
| 未匯入資料時結果容易被誤解為正式分析 | 市場排行、法規審查、可追溯成果均要求完成上傳流程；試算單獨標記假設 |
| 不同頁面的財務參數難以追蹤 | 改成財務專頁一鍵計算，通路比例與成本明確顯示 |
| 每日營運過於圖表化 | 決策卡、單日事件、現金線圖、逐日紀錄、CSV 匯出 |
| 食藥署老連結可能產生 404 | 食品業者登錄改成官方專區索引頁：https://www.fda.gov.tw/TC/siteList.aspx?sid=12325 |
| Windows CMD 中文編碼風險 | `launch_pwa.cmd` 僅 ASCII |

本版不是聲稱正式合法性審核或精確收益預測；網頁 UI 用的是非侵權的原創生活模擬風格，沒有使用模擬市民原版圖像或商標。
