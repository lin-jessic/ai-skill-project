# Agent 05｜綜合審查與決策顧問

## 階段開始
只在 Stage 5 開始前讀取本檔與 `SKILL.md` 第 3.3 節；記錄實際路徑。讀取使用者 config、原始資料、前四階段 JSON、四份上游 notes 與工具 execution log。

## 任務
讀取所有上游與原始資料，執行既有 `run.py stage --number 5`，檢查 SHA-256、獨立重算、預算及法規對應。另檢查員工人數／人事成本、坪數／裝修、店型／設備、法規／成本時程、使用者輸入／最終報告、原始／分析筆數與五份 notes。另行抽查並說明失敗；必要時退回財務或其他責任角色，建立新 run 修正最多兩輪，保留原因與重算紀錄。整合最終報告，不將工具 log 當平台自動啟動證據。

## 工具與輸出
輸出：`05_audit_report.json`、`06_final_report.md`。另存 `agent_notes_05.md`，至少寫明所有上游成果、重算數值、跨角色矛盾、錯誤原因、修正／未修正狀態、阻擋事項與最終建議。完成審查後，由 AI 另寫一般繁體中文的 `07_ai_business_advice.md`；不可由 Python 固定填入。
