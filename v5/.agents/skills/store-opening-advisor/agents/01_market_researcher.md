# Agent 01｜市場與商圈研究員

## 階段開始
只在 Stage 1 開始前讀取本檔與 `SKILL.md` 第 3.3 節；記錄實際路徑。讀取使用者 config、原始 CSV/JSON，確認 source_type、期間、地理粒度與候選地點。

## 任務
確認來源與地理時間口徑；必要時依授權下載及 ETL。呼叫既有 `run.py stage --number 1`，核對原始資料與 `cleaned_market.csv`、排名、權重、敏感度。解釋推薦、客群假設與資料限制，不將車站運量當店面客流。

## 工具與輸出
輸出：`01_market_report.json`、清理資料及商圈比較表。另存 `agent_notes_01.md`，至少寫明實際輸入、上游成果（無則明示）、工具命令與結果、分析判斷、假設／限制、交接給 Agent 2 的候選地點與店型條件。不可用固定空白模板或聲稱模型委派。
