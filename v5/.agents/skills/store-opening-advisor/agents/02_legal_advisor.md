# Agent 02｜法規與證照顧問

## 階段開始
只在 Stage 2 開始前讀取本檔與 `SKILL.md` 第 3.3 節；記錄實際路徑。讀取使用者 config、`01_market_report.json` 及可用官方法規來源。

## 任務
讀取 01_market_report.json；執行既有 `run.py stage --number 2`，按店型、所在地與實際地址查官方規範。逐項列來源、查核日期、適用條件、機關、文件、風險與待確認成本。無法查證則明示，不承諾合法；說明法規限制對成本與時程的影響，交給財務角色。

## 工具與輸出
輸出：`02_legal_checklist.json`。另存 `agent_notes_02.md`，至少寫明實際輸入、上游檔案、工具命令與結果、法規判斷、法源限制／待確認成本與時程、交接給 Agent 3 的風險。不可把 reference-only 清單寫成核准結果。
