# OpenShop LIFE｜台灣開店人生模擬器（v2 Studio）

**輸入 CSV/JSON 候選商圈檔案 → Agent 1 市場分析 → Agent 2 法規合規 → Agent 3 開店程序與審查 → 地點排行、日常經營與報告 ZIP。**

## 快速開啟（Windows / VS Code）

1. 解壓後進入 `v2/`，雙擊 **`啟動OpenShop_新版.cmd`**；或終端機執行 `python -m pip install -r requirements.txt`、`python -m streamlit run app.py`。
2. 在左側選擇 **20 種台灣常見店型**、縣市、預算、訂單與外送比例。
3. 在「📤 資料挑戰」匯入 CSV/JSON。可先用 `examples/DEMO_商圈資料_情境假設_非官方.csv` 試操作。**這份完全是合成情境，絕非台灣政府資料。**
4. 按「🚀 開始三角色完整審查」，依序產生 `outputs/studio_latest/01_market_report.json`、`02_legal_checklist.json`、`03_store_opening_plan.md`、`04_audit.json` 等。
5. 依序展示「🏆 商圈 PK」、「📜 法規通關」、「🪑 店面策略」、「🎮 每日經營」、「📈 財務」、「📦 報告／測試」。第七分頁可一次下載所有成果。

## 上傳格式

`district,population,competitors,footfall,rent,data_source`

範例：`桃園車站商圈,68000,125,53000,42000,教學情境假設／非官方數據`。欄位單位與統計期間需一致。資料缺值、負數、非數值會拒絕匯入。若教師提供不同格式，先依 `docs/上傳檔案欄位格式.md` 轉換。

## 功能與證據

- 20 種店型（餐飲、零售、服務）；依店型顯示不同基本參數與法遵事項。
- 可調權重的商圈相對排行，**只有匯入資料才會產生排行**；權重、人口、租金等均可查核。
- 法規入口與員工任務清單；未完成個案法規審查者絕不標記「已核准」。
- 內用／外帶／外送比重、平台費用、營收與損益兩平點試算。
- 可重現的逐日模擬事件、收益、現金變化圖；屬於**模擬資料**。
- A／B／C 三種 Skill 啟動測試提示；須在真正支援 Skill 的 AI 環境截圖取證。Streamlit 點選執行不代表模型自動觸發。

## 官方資料與真實性

原先提供的官方下載器在 `下載官方資料.cmd`，但外部政府資源可能變更，若 404 請使用 `references/verified_official_sources.md` 的穩定資料集入口重新下載，**不得把下載失敗解釋成「官方資料已備妥」**。使用者上傳資料也必須提供來源和觀測期間；沒有實際資料就不宣稱實證排名。

## 學習與作業證據

`SKILL.md` 按老師提供版本保留市場→法規→程序之順序。請錄製「教授檔案匯入 → 三 Agent 依序跑 → 報告下載 → A/B/C 實際 Skill 載入測試」完整流程；五分鐘錄影最好只展示一個已驗證場景。另須提供字幕、YouTube 非公開或公開影片與 AI Tutor 時間定位題目。

## 說明

本系統是**具可重現分析引擎的教學原型**，不是法律服務、正式開店審批或精準市場需求預測。官方資料由使用者自行取得；教學範例數字標註非官方。外送平台覆蓋、內用喜好沒有真實觀測值時僅能提供情境模型。

## 終端機檔案驗收（不經過網頁）

```cmd
python -m scripts.run_studio --input examples/DEMO_商圈資料_情境假設_非官方.csv --shop 手搖飲店 --city 桃園市
python -m pytest -q
```

此命令可用老師提供、符合指定欄位的 CSV/JSON 替換 `--input`。教授的檔案若欄名不同需先轉換，不可為了通過測試偽造觀測值。
