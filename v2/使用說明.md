# OpenShop AI v2｜官方資料下載器修正版

## 修正原因

原版 `scripts/download_official.py` **只自動下載 `tax`**；對 `population / metro / industry / restaurant` 一律輸出 `[MANUAL]`。這不是你的電腦操作錯誤。原版 `.cmd` 也把需要手動下載的訊息一筆帶過，看起來像全部沒有下載。

## 覆蓋方式

1. **不必重裝整套 v2，也不要刪除舊版資料。**
2. 將本包的 `下載官方資料.cmd` 複製到 `v2/` 根目錄，覆蓋原檔。
3. 將本包 `scripts/download_official.py` 放到 `v2/scripts/`，覆蓋原檔。
4. 雙擊 `v2/下載官方資料.cmd`。
5. 稅籍資料會嘗試自動下載；其餘四組會依次打開政府資料集頁面，請在瀏覽器下載 **CSV／JSON／ZIP／Excel 真正的資料檔**，回到跳出的選檔視窗選擇檔案。
6. 程式會自動複製到 `v2/data/raw/{tax,population,transit,market}/`，保留原檔名，並寫入 `v2/data/official_download_manifest.json`（附 SHA-256）。
7. 若政府頁面 404 或缺乏可下載資源，程式會顯示來源網址並允許跳過，**不會捏造官方資料**。

## 指令

```cmd
python -m scripts.download_official --check
python -m scripts.download_official --only tax
python -m streamlit run app.py
```

## 五個資料來源

- 稅籍登記：https://data.gov.tw/dataset/9400
- 村里人口：https://data.gov.tw/dataset/77132
- 桃園捷運運量：https://data.gov.tw/dataset/164957
- 商業登記家數：https://data.gov.tw/dataset/25346
- 餐飲業經營實況：https://data.gov.tw/dataset/94937

這裡只核實檔案存在、基本格式、雜湊值。**新版網站的「教授檔案挑戰」目前是上傳符合指定綱要的商圈 CSV／JSON。** 這五份大型官方資料不能單靠放入 `data/raw` 就直接變成商圈排行；還需要欄位映射、地區彙整、資料期間一致性檢核。不得把資料已收集誤稱為分析已完成。
